# Living Cost Comparison — brand kit

## Core idea

Living Cost Comparison is a calm, evidence-led decision tool. The visual system is based on a civic data publication rather than a consumer-finance dashboard.

The logo uses two brackets to represent places held to the same measurement standard. Two centre bars communicate comparison and difference.

## Logo assets

- `public/brand/logo-mark.svg` — primary mark for light backgrounds.
- `public/brand/logo-mark-reversed.svg` — reversed mark for dark backgrounds.
- `public/brand/logo-lockup.svg` — horizontal name lockup.
- `public/favicon.svg` — small-size favicon derived from the same geometry.

Keep clear space around the mark equal to the width of one centre bar. Do not rotate, add effects, recolour individual parts, or place the primary mark on a low-contrast background.

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| Ledger Ink | `#142B3D` | Primary text, dark fields, footer |
| Signal Blue | `#2F5BFF` | Actions, origin series, active states |
| Compare Gold | `#E5A82A` | Destination series, meaningful differences |
| Paper | `#F4F6F8` | Page background |
| Rule | `#D7DEE5` | Dividers and control boundaries |
| White | `#FFFFFF` | Working surfaces |

Signal Blue and Compare Gold have fixed semantic roles in comparison charts. Do not assign random colours to cities.

## Typography

- Primary: `Helvetica Neue`, Helvetica, Arial, system sans-serif.
- Data: `SFMono-Regular`, Consolas, monospace.
- Display: 48–56px desktop, 38–44px mobile, 1.02 line height.
- Body: 16px minimum, 1.65 line height.
- Labels: 12–13px, uppercase only for compact metadata.

## Layout

- 8-point spacing rhythm.
- Maximum content width: 1184px.
- One-pixel rules define sections and data cells.
- Corners are 6px for controls and 0–2px for analytical panels.
- Avoid gradients, glass effects, decorative blobs, floating pills and unnecessary iconography.
